# Suggested publication-grade figure plan (do not fabricate values)

F1. Sampling design map, sites/season/tide and raw-clean quality audit (only measured metadata).
F2. Taxonomic all-domain hierarchy: Bacteria, Archaea, Eukaryotes, Viruses, plastids, unclassified; distinguish read-based, SSU and contig assignments.
F3. Phylogenetic trees of key 18S rRNAs including ambiguous copepod and protist placements, show branch confidence and reference accessions.
F4. Contig size profile, N50, mapped read rate, coverage breadth, completeness vs contamination and MAG GTDB taxonomy.
F5. Gene/MAG functional heatmap (KO, eggNOG, DRAM2); normalized abundance with independent replicate uncertainty where available.
F6. Carbon input, CAZyme families/clusters and polymer degradation by functional guild.
F7. Separately resolved N and S pathway maps: nitrification, DNRA, denitrification, anammox, sulfate reduction, sulfur oxidation, DMSP.
F8. Phosphorus, salinity, metal, oxidative-stress and signaling systems (mechanistic gene evidence at every node).
F9. geNomad viral genomes/plasmids with CheckV quality, provirus status, host links labeled confidence.
F10. Multi-layer functional network as **hypothetical encoded potential** rather than direct observed ecological dynamics.
F11. When sufficient independent replicates exist: season/tide/salinity gradient, ordination and differential abundance with proper controls.
F12. Validation panel: targeted RT-qPCR, proteomics, isotope flux or enzyme activity assays if performed.

No single-sample analysis supports F11 without independent replicates.
